# SpreadJS 직원 근무 스케줄 대시보드 (Employee Work Schedule Dashboard)

SpreadJS를 활용하여 구현한 **직원 근무 스케줄 대시보드(Employee Work Schedule Dashboard) 샘플**입니다.

JavaScript 스프레드시트 컴포넌트인 **MESCIUS SpreadJS**를 사용하여 직원별 근무 일정과 스케줄을 웹 애플리케이션에서 관리하고 확인할 수 있는 대시보드를 구현할 수 있습니다.

본 샘플에서는 직원별 근무 스케줄 데이터를 스프레드시트 형태로 구성하고, 근무 일정을 한눈에 확인할 수 있는 웹 기반 대시보드를 제공합니다.

## 주요 기능

- SpreadJS 기반 웹 스프레드시트 구현
- 직원별 근무 스케줄 조회 및 관리
- 근무 일정 데이터 표시
- Excel과 유사한 스케줄 관리 화면 구성
- 수식 및 데이터 계산
- 차트를 이용한 근무 현황 시각화
- Excel 파일 가져오기 및 내보내기
- SpreadJS 파일(`.sjs`)을 이용한 대시보드 저장 및 로드

## 샘플 파일

| 파일 | 설명 |
| --- | --- |
| `직원 근무 스케줄 대시보드.xlsx` | 직원 근무 스케줄 대시보드 Excel 템플릿 |
| `직원 근무 스케줄 대시보드.sjs` | SpreadJS에서 사용하는 직원 근무 스케줄 대시보드 파일 |
| `샘플코드` | SpreadJS를 이용하여 대시보드를 구현하는 JavaScript 샘플 코드 |

## SpreadJS란?

**SpreadJS**는 웹 애플리케이션에서 Excel과 유사한 스프레드시트 기능을 구현할 수 있는 JavaScript 스프레드시트 컴포넌트입니다.

셀 편집, 수식, 차트, 테이블, 조건부 서식, Excel 파일 가져오기/내보내기 등 다양한 스프레드시트 기능을 제공하며, 웹 기반 업무 시스템에서 Excel 형태의 화면이나 대시보드를 구현하는 데 사용할 수 있습니다.

직원 근무 스케줄 관리뿐만 아니라 다음과 같은 업무 시스템을 구현하는 데 활용할 수 있습니다.

- 직원 근무 스케줄 관리
- 근태 관리
- 인력 배치 및 일정 관리
- 프로젝트 일정 관리
- 업무 현황 대시보드
- 인사 관리 시스템
- Excel 기반 업무 시스템의 웹 전환

## 직원 근무 스케줄 대시보드

이 샘플은 기존 Excel 기반의 직원 근무 스케줄을 **SpreadJS 기반 웹 스프레드시트 대시보드**로 구현하는 방법을 보여줍니다.

기존 Excel에서 관리하던 직원별 근무 일정과 스케줄을 웹 애플리케이션에서 조회하고 관리할 수 있으며, 스프레드시트와 차트를 활용하여 근무 현황을 시각적으로 확인할 수 있습니다.

이를 통해 기존 Excel 기반의 직원 스케줄 관리 업무를 웹 기반 시스템으로 전환하거나, 인사 및 근태 관리 시스템에 Excel과 유사한 스케줄 관리 기능을 추가할 수 있습니다.
